ML-Accelerated Metadynamics

Can a pretrained machine-learned potential stand in for a quantum-chemical reference — and where it can’t, can we correct it without retraining?

The long-term goal is a workflow where enhanced sampling runs on a machine-learned surrogate at the accuracy of the underlying quantum-chemical reference. Getting there means answering four questions in order: does an off-the-shelf potential agree with the reference at equilibrium, does that agreement survive bond breaking, can a lightweight correction close the gap that appears, and does that correction keep improving when fed more data.

Each pillar below is a 2–4 minute read. The detailed Studies remain the source of truth for methodology, full tables, convergence tests, and troubleshooting.

PILLAR 1

MACE ↔︎ xTB validation

Does off-the-shelf MACE-OFF23 reproduce GFN2-xTB for equilibrium water?

Yes. Forces correlate at r ≈ 0.99 and MD reproduces droplet structure.

PILLAR 2

Reactive chemistry

Does that agreement survive bond-forming chemistry?

No. Barriers differ by ~29 kcal/mol — a genuine difference between the two potential-energy surfaces, not a path-search artifact.

PILLAR 3

Post-training correction

Can a lightweight correction close that gap without touching the foundation model?

Largely, once. A targeted conservative Delta puts the certified saddle at 6.33 kcal/mol against an xTB target of 6.7.

PILLAR 4

Iterative calibration

Does repeating that correction with more targeted data keep improving it?

No. 42 further reference calculations did not improve on iteration 0 — a useful negative result.

The scientific chain

Each pillar exists because the previous one produced a specific question:

  1. Equilibrium agreement is strong — which makes the reactive test meaningful rather than a foregone conclusion.
  2. Reactive agreement fails, and the failure is localized to the transition-state region — which motivates correcting there rather than globally.
  3. Targeted correction works, once — which raises the obvious follow-up: does it keep working if iterated?
  4. It does not — which points at correction capacity, not reference-data quantity, as the next thing to test.

The Research Map shows how the individual studies attach to this chain. It is optional — everything on the main pages stands on its own.

Methods in one paragraph

Gas-phase and periodic GFN2/GFN1-xTB metadynamics (built-in Cartesian-RMSD bias), NVT, 0.5 fs timestep; analysis with ASE / NumPy / pandas. Reactions via xtb --path, relaxed concerted scans, and Sella saddle optimization with Hessian verification. Surrogate benchmarking with MACE-OFF23 (small) as an ASE calculator; corrections applied through a CorrectedCalculator wrapper so the foundation model is never modified. All code, data, and figures are in the repository; each study page links to its detailed FINDINGS document.

On the RMSD bias xTB biases along Cartesian RMSD to previously visited structures — not along any bond or angle. Every collective variable computed in analysis is a post-hoc descriptor, and Epot versus a CV is a sampled potential-energy landscape from a biased run, not a free-energy surface.
